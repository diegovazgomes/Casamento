# DEVAZI — AI Context

## Função deste arquivo

Este arquivo serve como contexto rápido para orientar ferramentas de IA, como Claude Code, VSCode Copilot e novos chats do ChatGPT, sobre a identidade, o posicionamento, o tom de voz e os princípios de produto da Devazi.

Use este documento sempre que for pedir ajustes de código, copy, UI, UX, landing page, Instagram, design system ou qualquer decisão relacionada à marca.

---

## Resumo da marca

A Devazi é uma plataforma premium brasileira de experiências digitais para casamento.

A marca cria sites de casamento sofisticados, com estética editorial, experiência mobile-first, RSVP, gestão de convidados, presentes, Pix, cartão e painel simples para o casal.

A Devazi não deve ser tratada apenas como:

- convite digital;
- site de casamento comum;
- plataforma de RSVP;
- ferramenta de templates.

A Devazi deve ser entendida como:

> Uma plataforma editorial de experiências digitais para casamento.

Frase central da marca:

> A forma mais elegante de criar o site do seu casamento.

Formulação conceitual:

> Design editorial aplicado à experiência digital do casamento.

A Devazi deve parecer:

A direção visual da Devazi deve ser editorial, premium, minimalista e contemporânea.

Evitar:

- visual extremamente feminino ou infantilizado;

- marfim;
- linho;
- off-white quente;
- off-black;
- ouro envelhecido discreto;
- bege sofisticado;
- tons de papel;

Princípio:

A paleta deve parecer mais editorial do que decorativa.

## Princípios de UX

Princípio central:

> A experiência da Devazi deve ser premium porque é simples.

O casal deve sentir:

- clareza;
- controle;
- tranquilidade;
- entusiasmo contido;
- segurança;
- refinamento;
- facilidade;
- progresso.

O casal nunca deve sentir:

- confusão;
- excesso de opções;
- medo de errar;
- aparência técnica;
- pressão comercial;
- interface genérica;
- falta de orientação.

Regras de UX:

- menos decisões, melhores resultados;
- personalização com curadoria;
- edição guiada;
- mobile-first real;
- microcopy como parte da experiência;
- completo sem parecer complexo;
- tecnologia invisível;
- autonomia com direção.

> Design premium sem aparência de IA ou template barato.

## Critérios para novas features

Uma nova feature deve ser adicionada se:

- simplifica a vida do casal;
- melhora a experiência do convidado;
- reforça a percepção premium;
- reduz trabalho manual;
- se integra com clareza ao produto;
- não aumenta ruído na interface.

Evitar features que:

- adicionam complexidade sem valor claro;
- transformam a plataforma em dashboard pesado;
- exigem muitas configurações;
- quebram o fluxo mobile;
- deixam a experiência com cara de software genérico.

---

## Critérios para novos templates

Um template Devazi deve:

- parecer editorial;
- ter boa hierarquia tipográfica;
- funcionar muito bem no celular;
- evitar clichês;
- preservar respiro;
- permitir personalização sem perder estética;
- parecer premium mesmo com poucas imagens;
- ter ritmo visual.

Um template não deve:

- depender de ornamentos excessivos;
- parecer convite pronto de marketplace;
- usar fontes clichês demais;
- ter muitos elementos decorativos;
- parecer gerado por IA;
- parecer infantil ou genérico.
